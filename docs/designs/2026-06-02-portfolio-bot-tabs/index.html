  • Automation rail stays context-only and avoids advice language.

Option 2

Ledger Inspector

  • Best if portfolio scanning is the dominant workflow.
  • More traditional financial-tool feel, less visual drama.
  • Bot tab mirrors the same ledger idea for runs and settings.

  • Strong separation between observation and allowed actions.
  • Darker, compact, action-oriented, with fewer table rows visible.
